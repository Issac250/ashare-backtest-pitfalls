# A 股回测避坑手册

回测曲线好看，先检查一下：信号什么时候知道，订单按什么价格成交，缺失记录删掉了谁，年化和基准又怎么算。

这本手册把这些问题拆成 12 个小例子。每章都有独立的 Python 脚本，你可以先运行，再改一项假设，看看数字为什么变了。正文引用的输出会在测试中与脚本核对。

例子都用合成数据，好处是能单独控制某一个问题。表里的收益是演示结果，不是策略推荐，也不是对真实市场量级的估计。

涉及订单的例子使用 [ashare-bt](https://github.com/Issac250/ashare-bt)：接入 pandas 日线和选股评分，按下一开盘成交，并处理涨跌停标记、整手和费用。它是日线近似模型，具体约定在引擎的 README 里。

每章沿用“现象 → 为什么会这样 → 最小复现 → 怎么防 → 一行自查”的顺序。只想排查某个问题，可以直接跳到对应章节。

## 跑一个例子

```bash
git clone https://github.com/Issac250/ashare-backtest-pitfalls
cd ashare-backtest-pitfalls
pip install -e '.[dev]'
python repro/01_close_price_fills.py
pytest
```

安装需要 Python 3.11+，会从 GitHub 安装固定版本的 `ashare-bt`，并使用固定版本的 NumPy、pandas，让脚本结果便于复核。

`pytest` 会逐个运行 12 个复现，检查脚本自己的断言，以及章节里引用的输出。换成自己的数据后，可以保留这些检查思路，但要重新核对成交、覆盖和估值口径。
