# A 股回测避坑手册

回测是怎么骗人的，以及怎么抓住它。

每一章讲一个坑，结构都一样：**现象 → 为什么会这样 → 最小复现 → 怎么防 → 一行自查**。每个复现都是一段能直接运行的脚本，只用合成数据，先打印"错的数"，再打印"对的数"，最后用一个 `assert` 确认两者的差别方向和正文说的一致。正文里的数字都是从这些脚本里跑出来的。

成交规则（次日开盘成交、开盘口径的涨跌停、T+1、整手、按总收益记账、退市强平）由开源回测引擎 [ashare-bt](https://github.com/Issac250/ashare-bt) 实现。

## 运行复现

```bash
git clone https://github.com/Issac250/ashare-backtest-pitfalls
cd ashare-backtest-pitfalls
pip install -e ".[dev]"
python repro/01_close_price_fills.py   # 任意一章
pytest                                 # 全部 12 章，逐个运行
```

## 读之前要知道的

- **合成数据只用来展示机制。** 每个复现都刻意把机制放大，让方向看得清楚，数字的大小不代表真实市场里的量级。真实数据上的量级，要在你自己的数据上用同样的方法重新测量。
- **每一条错误都会给出看上去很合理的数字。** 这正是它们危险的地方。
