# 11 全样本 Sharpe 1.05，最近一段怎么是负的？

> 一个全期数字，可能把早期的好表现和近期的差表现平均在一起。先把时间轴拆开看看。

## 现象

全样本 Sharpe 是 1.05。按时间切成三段，分别是 2.19、1.56 和 −0.60。

只报第一个数字，看不出近期这段经历。只报最后一个，也会丢掉过去的信息。把它们放在一起，才方便判断表现是否随时间改变。

## 为什么会这样

同一个评分特征，在不同阶段未必带来相同收益。全样本指标会把所有阶段混在一起，早期的好表现可以抬高汇总结果。

本章在生成数据时设定：前两段的特征有正溢价，第三段溢价为零。原因是为了展示统计效果，不是用它断言现实里的某个因子已经失效。

还有一个细节：前两段设定的溢价相同，算出的 Sharpe 却是 2.19 和 1.56。这组数据本身就有随机波动，不能把每一次指标下降都解释成结构性衰减。

近期表现值得单列，但它也不是未来表现的保证。实际数据里，还要结合区间长度、费用和不确定性判断。

## 最小复现

[`repro/11_one_era_dominates.py`](https://github.com/Issac250/ashare-backtest-pitfalls/blob/main/repro/11_one_era_dominates.py)：生成 200 只股票、1,500 个交易日。特征 x 在前 1,000 日带来正溢价，之后设为零。用引擎持有评分最高的 20 只，每 5 个信号日调仓，计入默认费用，再对同一条日收益序列分段计算 Sharpe。

```bash
python repro/11_one_era_dominates.py
```

```text
full sample  2018-01-03 -> 2023-10-02  Sharpe 1.05  (wrong to quote alone)
segment 1    2018-01-03 -> 2019-12-02  Sharpe 2.19
segment 2    2019-12-03 -> 2021-11-01  Sharpe 1.56
segment 3    2021-11-02 -> 2023-10-02  Sharpe -0.60
latest segment Sharpe (right to report next to it): -0.60
```

全样本 1.05，最后一段 −0.60。前两段较好的结果，让全期指标仍然保持为正。

这次我们知道溢价何时归零，因为它是合成数据的设定。真实数据里的一个负 Sharpe，只能描述该区间的样本表现，不能单独证明策略永久失效。

## 怎么防

同时列出全样本和预先选定的近期区间。可以用不重叠分段观察变化，也可以画滚动指标，但滚动窗口会共享数据，不能当成独立证据。

各段重新核对成本、覆盖和换手，避免把全期的平均情况直接套过去。分段方式也不要看到结果以后反复挑，直到挑出最好看的解释。
