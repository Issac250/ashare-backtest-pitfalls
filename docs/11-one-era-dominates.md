# 11 全样本数字靠一个已经结束的时代撑着

> 一个因子前三分之二的样本有效，最后三分之一失效了。全样本 Sharpe 仍然好看，因为它把好时代平均了进去。

## 现象

全样本 Sharpe 1.05，看上去是一个不错的策略。按时间切成三段，依次是 2.19、1.56、−0.60。

## 为什么会这样

**因子溢价**（factor premium，某个特征长期带来的超额收益）不是常数。被发现、变得拥挤、规则变化、市场结构变化，都会让它衰减。

**全样本平均会把好时代摊进来。** 一个十几年窗口上的漂亮数字，可能完全靠前面几年撑着。A 股历史上有过持续数年的风格行情，一段风格行情就足以撑起一整段回测。**最近一段才是"今天真去做会是什么感觉"的诚实估计。**

**反过来也成立：偏差会被平静的时代压低。** 成本、数据缺口、幸存者偏差这些东西，全期估出来的值是各段平均的结果，不能直接套到子区间上，要在你关心的那一段上重新测量。

**分段数字也有噪音，措辞要跟着证据走。** 下面复现里，第 1 段和第 2 段的真实溢价完全一样，Sharpe 却分别是 2.19 和 1.56，这么大的差距纯粹是噪音。所以最近一段的 −0.60 不能说成"证明已经失效"，只能说成"在这段样本里没有看到它还有效"。

## 最小复现

[`repro/11_one_era_dominates.py`](https://github.com/Issac250/ashare-backtest-pitfalls/blob/main/repro/11_one_era_dominates.py)：200 只合成股票，约 6 年。一个可观测的特征 x 在前三分之二的时间里带来正的溢价，最后三分之一溢价为 0。用 `ashare-bt` 买 x 最高的 20 只，每 5 天调仓，计入默认成本。

```bash
python repro/11_one_era_dominates.py
```

```text
full sample  2018-01-03 -> 2023-10-02  Sharpe 1.05  (wrong to quote alone)
segment 1    2018-01-03 -> 2019-12-02  Sharpe 2.19
segment 2    2019-12-03 -> 2021-11-01  Sharpe 1.56
segment 3    2021-11-02 -> 2023-10-02  Sharpe -0.60
latest segment Sharpe (right to report next to it): -0.60
```

- **错的做法**：只报全样本的 1.05。
- **对的做法**：把最近一段的 −0.60 和它放在一起报。

## 怎么防

1. 永远单独报最近一段（比如最近 3 年），和全样本数字并排放。
2. 按不重叠的时段切开来报（三段，或滚动 3 年窗口），看是不是一路单调衰减。
3. 成本、偏差、数据缺口都在子区间上重新测量，别拿全期均值代入。
4. 别把一个时代的数字当成永久的优势。
