# 07 挑出最大的赢家，怎么挑出了一堆停牌股？

> 市场跌了，停牌股的记录价格却没动。它看起来很抗跌，也可能只是还没更新价格。

## 现象

按未来 120 个交易日的相对收益，挑出表现最好的股票读案例。名单里出现不少窗口内停过牌的公司。

如果只看两组的平均收益，差别又不大。这时候要检查的，是停牌样本在你挑出的那批“赢家”里占多少。

## 为什么会这样

假设市场跌了 20%，一只停牌股仍沿用之前的价格。按记录价格计算，它暂时没有跌，相对市场就显得领先了。

这不等于账户没有风险，也不等于能按这个价格卖出。股票复牌以后，价格还可能变化。

本章让复牌价格补到模型设定的位置。多数窗口里，这种暂时领先会被后来的变化抵消；但窗口结束时仍未复牌的股票，可能还保留着这段记录价格上的优势。

所以看全部样本的均值，与专门挑前 1% 读案例，是两种抽样方式。整体变化不大，也可能影响你读到的案例。

[第 03 章](03-halt-resumption-gap.md) 检查的是入场时买不买得进；这里检查的是后续窗口内的价格记录是否影响了相对收益排名。

## 最小复现

[`repro/07_halt_relative_return.py`](https://github.com/Issac250/ashare-backtest-pitfalls/blob/main/repro/07_halt_relative_return.py)：1,000 只合成股票，600 个交易日，中间设一段 40 个交易日的市场下跌。120 只股票各有一次长停牌，记录价格冻结，复牌时补到模型价格。每 20 个交易日取快照，计算未来 120 日相对横截面均值的对数收益，并标记窗口内停牌超过 20 天的记录。

```bash
python repro/07_halt_relative_return.py
```

```text
snapshots with >20 halted sessions ahead: 4.1% of 19000
mean test (wrong check): relative return, halted +0.87% vs others -0.04% -- looks harmless
share of the top 10% winners that were halted: 5.9% (1.5x)
tail test (right check): share of the top 1% winners that were halted: 14.7% (3.6x the base rate)
```

停牌标记占全部记录的 4.1%，在前 10% 赢家中占 5.9%，到了前 1% 则占 14.7%，约为基础比例的 3.6 倍。

本例的对数收益均值分别是 +0.87% 和 −0.04%。均值检查本身并没有错，只是它回答不了“我挑出来的极端案例有没有被停牌记录影响”这个问题。

## 怎么防

读头部案例前，先标出每个观察窗口内的停牌天数，比较它们在全样本和头部样本中的占比。

可以再报告排除长停牌窗口后的结果，作为研究敏感性检查。这里用到了未来窗口的信息，不能直接把这种事后剔除当成信号日就能使用的选股条件。

## 一行自查

> 这只股票排得靠前，是价格真的表现好，还是窗口结束时还没更新？
