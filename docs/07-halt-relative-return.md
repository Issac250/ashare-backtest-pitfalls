# 07 停牌造出来的相对收益：均值看不出，尾巴里全是它

> 大跌期间停牌的股票价格被钉住，市场在跌，它的"相对收益"就凭空变大。看均值发现不了，可最大的赢家里挤满了这种股票。

## 现象

按未来 120 日的相对收益挑出"最大的赢家"来读案例，结果发现不少是暴跌期间停了牌的股票。它们不是赢家，只是被冻住了。

## 为什么会这样

**相对收益 = 个股收益 − 市场收益。** 停牌期间个股价格不动，市场在跌，相对收益就凭空变大了。

**这和[第 03 章](03-halt-resumption-gap.md)不是一回事。** 第 03 章讲的是停牌期间买不进去；这里的样本在快照日完全可以交易，只是它往后看的那段窗口里含有停牌。被比较的市场在动，它自己不动。

**均值检验看不见它。** 复牌后价格会补涨或补跌，回到本来该在的位置，所以平均下来，它的相对收益和别的股票差不多。但那些窗口结束时还没复牌、或正好停牌跨过暴跌的样本，会冲进两侧的极端尾巴。

**读案例，恰恰是在尾巴里抽样。** 所以"挑最大的赢家来读"这类分析最容易被污染。

**年代很重要。** A 股在 2015 年股灾期间出现过大面积停牌；后来监管收紧了停复牌规则，长期停牌少了很多。同一种分析，放在不同年代，受污染的程度不一样。

## 最小复现

[`repro/07_halt_relative_return.py`](https://github.com/Issac250/ashare-backtest-pitfalls/blob/main/repro/07_halt_relative_return.py)：1,000 只合成股票，600 个交易日，中间有两个月的暴跌。12% 的股票各有一段 30 到 80 天的长停牌，停牌期间价格冻结，复牌时补到应有的位置。每 20 天取一次快照，计算之后 120 日相对于市场的对数收益；如果这段窗口里停牌超过 20 天，就把样本标记为"停牌"。

```bash
python repro/07_halt_relative_return.py
```

```text
snapshots with >20 halted sessions ahead: 4.1% of 19000
mean test (wrong check): relative return, halted +0.87% vs others -0.04% -- looks harmless
share of the top 10% winners that were halted: 5.9% (1.5x)
tail test (right check): share of the top 1% winners that were halted: 14.7% (3.6x the base rate)
```

- **错的检查**：比较均值，停牌样本 +0.87%，其他样本 −0.04%，差别不大，看上去无害。
- **对的检查**：看尾巴。停牌样本只占全部的 4.1%，却占了前 1% 赢家的 14.7%，是基础比例的 3.6 倍。

## 怎么防

1. 凡是按前瞻收益排序挑样本的分析，先剔掉前瞻窗口里停牌超过阈值的样本（比如 120 日窗口里停牌超过 20 天）。
2. 检查有没有被污染，要看它在尾巴里的占比，只看均值不够。
3. 报告"头部赢家有什么共同特征"之前，先数一数头部里有多少是停过牌的。
