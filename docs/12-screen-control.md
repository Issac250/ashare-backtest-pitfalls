# 12 加了筛选收益反而低了，这个条件就没用吗？

> 从 400 只缩到 160 只，既换了股票，也缩小了可选范围。多一个同样大小的随机池，能把两个问题拆开看。

## 现象

加一个筛选条件，CAGR 从 +31.1% 降到 +29.8%。如果只想知道哪个最终组合在本例里赚得多，全池确实更高。

但如果想问“这个条件有没有挑选能力”，还需要看：随便留 160 只，会怎样？

## 为什么会这样

本章的评分本来有预测信息。缩小池子以后，可选的高分股票也会减少；与此同时，筛选条件留下的股票又有一点额外优势。

因此，“筛选后减全池”同时包含了选谁和少了多少选择的影响。它对最终组合表现有用，但不够单独解释筛选条件的作用。

再从原池子随机留下同样的 160 只，保持评分、持股数和执行约定一致，就多了一个匹配池子大小的对照。换几个随机种子，也能看到随机选法之间差多少。

随机子集不是所有筛选问题的唯一答案。如果筛选还改变板块、市值、流动性或换手，还要根据研究问题继续匹配这些差别。少数几个随机种子的结果范围，也不能当成置信区间。

## 最小复现

[`repro/12_screen_control.py`](https://github.com/Issac250/ashare-backtest-pitfalls/blob/main/repro/12_screen_control.py)：400 只合成股票，特征 x 带来正溢价，引擎持有评分最高的 20 只，每 10 个信号日调仓。筛选留下固定的 160 只，被排除的股票额外带一点负漂移。再用 5 个固定种子各取一个 160 只的随机池。

```bash
python repro/12_screen_control.py
```

```text
full pool (400)              CAGR: +31.1%
screened pool (160)         CAGR: +29.8%
random pools (160) x5       CAGR: +23.1%  (range +20.6% .. +25.2%)
screen - full pool        (wrong control): -1.3% a year
screen - same-size random (right control): +6.6% a year
```

筛选比全池低 1.3 个百分点，却比同样大小的随机池均值高 6.6 个百分点，并高于这次五个随机池的结果。

两种对照并不矛盾：这个条件在合成设定中有挑选价值，但最终筛选组合仍没超过全池。要决定是否采用它，还要看你关心的是最终收益、风险，还是条件本身的增量信息。

## 怎么防

一起报告全池、筛选池和同样大小随机池的表现，并列出各自的股票数量。不要只保留能支持结论的那一种对照。

随机池先用多个种子做检查；需要统计推断时，再扩大重复并考虑时间依赖等问题。评估加权或退出规则时，也要核对缺失处理、触发频率和候选范围是否一致。
