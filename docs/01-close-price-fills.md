# 01 收盘价成交不了：买卖价差跳动

> 用"今天收盘到明天收盘"算收益，一个毫无信息的反转信号也能年化 +19.9%；换成次日开盘成交，它是 +0.5%。

## 现象

最常见的回测写法：每天收盘后算信号，再拿"今天收盘到明天收盘"的涨跌幅当持仓收益。短周期反转信号（买昨天跌得最多的）在这种写法下往往好得惊人，换成次日开盘成交，收益就没了。

## 为什么会这样

**成交价不等于价值。** 收盘价只是最后一笔成交的价格。一只价值 10.00 元的股票，买一 9.95、卖一 10.05，收盘价落在哪边，只看最后一笔是主动卖还是主动买。这个现象叫**买卖价差跳动**（bid-ask bounce）：价值一分没变，打印出来的价格却在买一和卖一之间来回跳。

**反转信号会专门挑中收盘打在买一上的股票。** 它们看起来"跌了"。下一个收盘价有一半概率打在卖一，看起来又"反弹"了。回测把这一来一回记成收益，其实那只是打印噪音。

**这笔钱你收不到。** 真去买，你付的是卖一；真去卖，你拿到的是买一。方向和回测记账的正好相反。所以不是"收益被成本吃掉了"，是**这笔收益从来就不存在**。

**偏差随价差变宽而放大。** 越冷门、价差越宽的股票，假收益越大，而偏爱冷门小票的信号恰好最爱交易它们。

还有一个更直接的问题：用收盘价算信号，又按同一个收盘价成交。这是**未来函数**（look-ahead bias），也就是用了决策那一刻还拿不到的信息。信号算出来的时候，那个价格已经过去了。

## 最小复现

[`repro/01_close_price_fills.py`](https://github.com/Issac250/ashare-backtest-pitfalls/blob/main/repro/01_close_price_fills.py)：200 只合成股票，**真实价值是纯随机游走**，任何策略都不该赚钱。每个开盘价、收盘价随机落在买一或卖一上，价差 0.5%。信号是昨天跌得最多的 20 只，每天调仓。

```bash
python repro/01_close_price_fills.py
```

```text
close-to-close, no costs (wrong) CAGR: +19.9%
next-open fill, no costs (right) CAGR: +0.5%
next-open fill, default costs    CAGR: -38.2%
```

- **错的数 +19.9%**：收盘到收盘、零成本。
- **对的数 +0.5%**：同一信号、同样零成本，只是改成次日开盘成交。它约等于 0，这是对的，因为真实价值本来就不可预测。
- 再加上 `ashare-bt` 默认的佣金、印花税和 5bp 滑点，每天换手的代价是 −38.2%。

## 怎么防

1. 只用信号算出来**之后**才出现的价格成交：t 日收盘出信号，t+1 日开盘成交。`ashare-bt` 默认就是这样。
2. 收盘到收盘的收益只能拿来给想法排个先后，不能当可交易收益报出来。
3. 短周期信号要单独估价差：把成交价换成"买在卖一、卖在买一"再跑一遍。
4. 结果越依赖冷门小票，越要先怀疑这一条。
